# Composio

Plugin pack for [Composio](https://composio.dev) — one connection that gives an
agent **1,600+ app toolkits** (Gmail, Slack, GitHub, Notion, Linear, HubSpot,
Google Sheets, Stripe, and more) plus a remote workbench.

The pack is portable: a `plugin.json` manifest, the upstream `composio` Agent
Skill, and an MCP server definition. It works with any agent that reads
`SKILL.md`, and the same MCP endpoint works with any MCP client.

```
composio/
  plugin.json                 universal manifest
  skills/composio/SKILL.md    routing + setup guidance (upstream)
  mcp/composio.mcp.json       streamable-HTTP MCP definition
  toolkits.json               curated offline seed for the Plugins panel
```

## Two products, two credentials

| | Composio For You | Composio Platform |
|---|---|---|
| For | your own agent, your own apps | an app where **your users** connect accounts |
| Credential | consumer key `ck_...` | project API key `COMPOSIO_API_KEY` |
| Surface | MCP or CLI | SDK session |
| Header | `x-consumer-api-key` | `x-api-key` |

The Plugins tab stores both. Keys are written to `data/composio.json` with mode
`0600` and are never returned by the API. Environment variables
(`COMPOSIO_CONSUMER_KEY`, `COMPOSIO_API_KEY`) take precedence over the store.

Get a consumer key from **dashboard.composio.dev → For You → AI Clients**. Get a
project key from **Platform → Settings → API keys**.

## MCP setup

Endpoint: `https://connect.composio.dev/mcp` (streamable HTTP).

Generic / Claude Code (`${VAR}` expansion):

```json
{
  "mcpServers": {
    "composio": {
      "type": "http",
      "url": "https://connect.composio.dev/mcp",
      "headers": { "x-consumer-api-key": "${COMPOSIO_CONSUMER_KEY}" }
    }
  }
}
```

OpenCode (`~/.config/opencode/opencode.jsonc`, `{env:VAR}` expansion):

```jsonc
{
  "mcp": {
    "composio": {
      "type": "remote",
      "url": "https://connect.composio.dev/mcp",
      "headers": { "x-consumer-api-key": "{env:COMPOSIO_CONSUMER_KEY}" },
      "enabled": true
    }
  }
}
```

Gemini CLI / Antigravity, Cursor, and Claude Code variants are generated by the
Plugins tab (**Composio → Wire MCP**) and written with a timestamped backup.

The seven MCP meta-tools handle discovery, authorization, execution, and remote
sandboxes:

`COMPOSIO_SEARCH_TOOLS` · `COMPOSIO_GET_TOOL_SCHEMAS` ·
`COMPOSIO_MULTI_EXECUTE_TOOL` · `COMPOSIO_MANAGE_CONNECTIONS` ·
`COMPOSIO_WAIT_FOR_CONNECTIONS` · `COMPOSIO_REMOTE_WORKBENCH` ·
`COMPOSIO_REMOTE_BASH_TOOL`

## CLI and SDK

```bash
# CLI (installs to ~/.composio, links into ~/.local/bin)
curl -fsSL https://composio.dev/install | sh
composio login

# Python SDK (3.11–3.15)
python3 -m venv .cache/composio-venv
.cache/composio-venv/bin/pip install composio
```

```python
from composio import Composio

composio = Composio()                 # reads COMPOSIO_API_KEY
session = composio.sessions.create(user_id="user_123")
tools = session.tools()               # meta-tools, not 1,600 schemas
```

Sessions are the current integration path. `composio-core` is the legacy v1
package — do not install it.

## Install

From the OS Plugins tab: **Composio → Install plugin**. Or:

```bash
curl -X POST http://localhost:8080/api/composio/install \
  -H 'Content-Type: application/json' -d '{}'
```

This copies the pack to `~/.agents/plugins/composio` and links the skill into the
detected agent skill directories.
