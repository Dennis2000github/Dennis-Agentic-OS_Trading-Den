# Welcome to the Vault

This is your **Obsidian-compatible** knowledge base, served by DENNIS Agentic OS. Notes are plain Markdown files stored in `vault/`.

## Try this

- Create a note with the **New note** button.
- Link notes with `[[Wikilinks]]` — open [[Ideas]] to see one.
- Use the **Graph** tab to visualise how notes connect.
- Everything you write stays on disk as `.md` and opens in Obsidian too.

See also: [[Ideas]] and [[Projects]].
